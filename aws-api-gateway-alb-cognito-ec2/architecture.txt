──────────────────────────────────────────────────────────────────────────

  Client                    Cognito                    Lambda Triggers
    │                          │                             │
    │── InitiateAuth ─────────►│                             │
    │   (CUSTOM_AUTH, email)   │──── DefineAuthChallenge ──►│
    │                          │   session=[] → CUSTOM_CHALLENGE
    │◄── CUSTOM_CHALLENGE ─────│◄────────────────────────────│
    │    publicChallengeParams  │──── CreateAuthChallenge ──►│
    │                          │◄────────────────────────────│
    │                          │
    │── RespondToChallenge ────►│
    │   ANSWER: {email,password}│──── VerifyAuthChallenge ──►│
    │                          │         │                   │
    │                          │         ▼                   │
    │                          │    RBAC EC2 POST            │
    │                          │    /api/auth/login          │
    │                          │         │                   │
    │                          │         ▼                   │
    │                          │    PostgreSQL               │
    │                          │    SELECT * FROM users      │
